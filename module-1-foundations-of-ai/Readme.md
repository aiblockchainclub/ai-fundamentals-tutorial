## **Module 1: Foundations of AI**

### **Project: AI Basics Project**

**Objective:** Predict housing prices using a linear regression model.

### **Setup Instructions:**

1. Clone this repository:

   ```bash
   git clone https://github.com/aiblockchainclub/ai-fundamentals-tutorial.git
   cd ai-fundamentals-tutorial/module-1-foundations-of-ai
   ```

2. install the dependencies

   ```
   pip install -r requirements.txt

   ```

3. Run the script
   ```bash
   python house-prediction.py
   ```
